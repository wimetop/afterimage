## Short description

Designed and developed Afterimage, an experimental AI video generation studio built as an immersive digital experience rather than a conventional SaaS dashboard. The interface combines cinematic art direction, an interactive generation chamber, a layered frame sculpture, a filterable film archive, and a professional editing timeline.

## Full description

Afterimage is a concept product for transforming written ideas into moving images. The main goal was to make the experience feel like entering an imagination engine: tactile, cinematic, spatial, and alive.

The first viewport is a generation chamber with oversized editorial typography, a suspended stack of cinematic frames, technical coordinates, film metadata, and a command composer integrated into the composition. When the user starts a render, the interface becomes a simulated render machine with six stages: parsing language, building the world, estimating motion, synthesizing frames, temporal coherence, and final render.

The generated works section uses an asymmetric contact-sheet layout with different aspect ratios and custom surreal film stills. Each frame has its own metadata, hover treatment, playback indicator, and accessible preview dialog.

The laboratory section reinterprets a creative editing tool as a web art installation. It includes a responsive preview, transport controls, a seekable playhead, prompt and frame tracks, a motion curve, and a sound visualization.

The experience was designed from scratch with a graphite and acid-chartreuse palette, Archivo display typography, DM Mono metadata, grain texture, perspective motion, pointer-reactive frame layers, responsive layouts, keyboard focus states, reduced-motion support, and native scrolling.

The functionality is intentionally mocked for the concept presentation: render progress, cancellation, previews, filters, playback, and timeline seeking are fully interactive without a backend.
